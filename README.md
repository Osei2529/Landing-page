#Landing Page

A landing page built from a provided design as part of The Odin Project's Foundations course. This project practices building a full page layout from scratch using Flexbox, working from an image and a color/font specification rather than a guided step-by-step exercise.

### What this demonstrates
- Building a multi-section page layout using Flexbox
- Translating a visual design into HTML and CSS
- Working with fonts, colors, and spacing to match a spec
- Structuring semantic HTML (header, nav, section, footer, blockquote)
- Git and GitHub workflow: commits, pushing, and deploying via GitHub Pages

### Live site
https://osei2529.github.io/Landing-page

## Sections
- Header with logo and navigation links
- Hero section with heading, subtext, and call-to-action button
- Information section with four illustrated info cards
- Testimonial/quote section
- Call-to-action banner
- Footer
